# Ideas

Things we might build. Nothing here is planned or promised. Before starting one, check it against
Chirp's scope and the rules in [AGENTS.md](../AGENTS.md).

## Live translation

Translate speech as it is heard, for example during a meeting.

- Reference: [wquguru/cicada](https://github.com/wquguru/cicada), an open-source live translation
  project. Not reviewed yet: check its licence against GPL-3.0, which models it uses, and whether it
  runs fully on the Mac before borrowing anything.
- Chirp is English only today, so this would be its first feature that deals with other languages.
  Decide that first.
